3

Name one North Star and the three inputs that move it

Define our North Star metric — the ONE number that best represents whether we're winning — and the 3 input metrics that move it.

North StarThe one number that tells you whether you're winning. It's a result, so you can't move it directly.

3 input metricsThe levers your team can pull this week. Move these and the North Star follows.

The trapA dashboard made only of results is a report card. You need the inputs too.

4

Make it ask before it answers

QUESTION 2What decisions do they need this dashboard to inform?

The full prompt
Act as a performance measurement expert. Design a KPI dashboard for
[function / initiative] using the Balanced Scorecard structure
(Financial, Customer, Process, Learning & Growth).

Rules:
- Maximum 8 metrics total
- Each must be classified as leading or lagging
- Each must have a target, a threshold (amber), and an alarm (red)
- Each must map to a decision it triggers — no metric without a decision

Also define our North Star metric — the ONE number that best represents
whether we're winning — and the 3 input metrics that move it.

Ask me first:
- Who is the primary audience — operator, exec, or board?
- What decisions do they need this dashboard to inform?
- What data can we actually get weekly vs. monthly vs. quarterly?
What you'll get back

A decision tool, not a data dump.

A clean North Star and its input tree, plus eight metrics across the scorecard. Each one has its thresholds set and a decision it triggers. (Illustrative example.)
